## Please provide a specific example of how you have built or used AI tools to improve project management efficiency, automate a process, or accelerate project execution.

The first deliverable for every Solenzo client is an audit of their online presence, and doing it by hand was slow and inconsistent. I turned it into an automated workflow: it pulls a business's data, uses LLM API calls to score it against a nine-part framework I built, and generates the findings and next steps. To keep the AI output reliable, I wrote rubric-based grading criteria and score the outputs against them. That workflow has run on 180+ businesses.

On the delivery side, I built 20+ automated workflows in GoHighLevel, using n8n, Make, and Zapier with webhooks and API calls, that handle client onboarding steps, scheduling confirmations and reminders, and follow up that I used to do manually. The result is that projects keep moving between meetings without me chasing every task, and my time goes to the decisions that need a person.
