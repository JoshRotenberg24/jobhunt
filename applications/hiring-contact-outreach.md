## Sequencing rule for all of the above

First touch sent the day the contact was confirmed (today, all six live ones). If no
reply by the follow-up date, send a second touch that's shorter than the first with one
new detail or a different CTA, not a repeat. Stop after two touches unless a reply
changes status. Update this file's Status column as each one moves (sent → replied →
call booked / no response → stop).
