## Timeline fix (the flagged issue)

An earlier reviewer read the resume's Level Agency entry (Sep 2024–Feb 2025) as reading
out of order under Solenzo (Feb 2024–Present), because Level Agency started five months
after Solenzo but is a shorter, concluded stint sitting inside Solenzo's still-open
window. The dates were never wrong — end-date-descending order is standard and this
resume already followed it — but the *overlap* wasn't explained, so it read as a
possible error.

**Fix applied:** the Level Agency location line now reads "Remote (concurrent with
Solenzo LLC)," and its first bullet states the overlap directly: "Ran this client-
strategist engagement concurrently with founding and operating Solenzo LLC full-time."
This should preempt the question rather than leave a reviewer to guess.

which opened an unexplained ~6-month gap between Wix (ends Aug 2022) and Birdeye (starts
