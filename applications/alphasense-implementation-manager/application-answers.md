# AlphaSense — Application Answers

## At your busiest point, how many separate customer onboarding programs or rollouts were you actively managing at the same time?

At Wix, at my peak I was managing about 25 onboardings at the same time, while launching 25+ new clients a month and leading the onboarding team. Simple launches I closed on the first call, so the open load was mostly the more complex builds that needed planned production across several sessions. I tracked every one in Salesforce using the onboarding fields I'd defined for the team, so I could see what was stalled before the client had to ask.
