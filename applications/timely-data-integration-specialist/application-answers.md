# Timely, Data Integration Specialist: application answers

## What is one SIS that you have deep familiarity with? In what capacity?

I haven't worked inside a Student Information System, and I'd rather say that plainly than stretch something. The closest equivalent is the systems of record I've administered for clients: CRMs like GoHighLevel, HubSpot, and Salesforce, where I've designed the data structure (fields, lifecycle stages, user roles and permissions), set data-hygiene rules, and moved records in and out. At Accelo I worked inside a practice-management (PSA) platform, scoping how client data, projects, and workflows would be structured and guiding the API integrations around it. I'd expect to learn PowerSchool or Infinite Campus quickly because the underlying work, understanding a data model and getting clean data in and out, is the same.

## What is your experience manipulating or managing scheduling-related data with this SIS?

Not with an SIS. The scheduling data I've managed is appointment and booking data: at Solenzo I built automated booking workflows in GoHighLevel that create appointments, send SMS and email confirmations and reminders, and route no-shows into recovery sequences, which means keeping calendar, contact, and status data consistent across systems. It's a different domain from master scheduling, but it's real experience with time-based records where one bad field breaks everything downstream.

## What experience do you have with external (third-party) integrations?

This is most of my day-to-day work. At Solenzo I connect client CRMs, websites, and reporting tools through REST APIs, Zapier, Make, and n8n, and write Python and JavaScript in custom code steps when a standard connector can't handle the data. I write SQL against BigQuery and GA4 data and Power BI data models, and check that records match across systems before clients rely on them. At Accelo I guided customers through API integrations between Accelo and their other tools and built Zapier automations connecting the platform to clients' stacks. At Birdeye, the core of the offer was syndicating each customer's business data out to third-party listing sites through Birdeye's data-aggregator solution, and I onboarded partners onto it. I document every integration so the next person can maintain it.
