# AGent Energy — Application Answers

## Tell us about a time you kept many customers, projects, or tasks moving at once. How did you stay organized? (3-5 sentences, 350 chars)

At Wix I managed about 25 onboardings at once while launching 25+ clients a month. I tracked every one in Salesforce using onboarding fields I'd defined for the team, so status and next steps were always visible. Simple launches I closed on the first call, which kept my open list focused on the complex builds.

## Describe something complex you had to learn quickly. How did you get up to speed? (3-5 sentences)

At Solenzo I moved past no-code automation into direct API work: webhooks, REST calls, LLM APIs, and reading JSON payloads. I learned by building real client workflows, using AI tools to explain errors and documentation as I went. I tested each step before go-live. Now I build and debug those integrations on my own.
