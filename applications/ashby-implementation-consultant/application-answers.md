## Most complex product (3-4 sentences)

Accelo, a platform for agencies and professional-services firms that combines CRM, project management, time tracking, and invoicing and billing in one system. It was complex because every module fed the next: how a firm structured its projects determined how time was logged, and that determined how it billed. No two firms ran the same way, so a setup decision that worked for one could break billing for another. My job was to map each firm's workflow and build a sequenced implementation plan deciding which systems to change and in what order before handing it to the implementation team.
